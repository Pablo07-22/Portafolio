Sobre mí

Soy Juan Pablo Navas Acosta, de Colombia, y estoy construyendo mi camino como desarrollador de software. Me gusta crear sistemas que resuelven problemas reales, desde una carta digital para una cafetería hasta un bot que recibe pedidos por Telegram.

Trabajo con Java y Spring Boot para aplicaciones con lógica sólida, con Python y JavaScript para scripts y páginas web, y con SQL para guardar y consultar la información. También uso n8n para automatizar tareas.

Soy puntual, me comunico con claridad y disfruto aprender tecnologías nuevas con cada proyecto.

Mis proyectos

Tecno Store

Aplicación de consola con sesión de administrador y de cliente. El cliente compra celulares; el administrador agrega empleados y celulares, y consulta los reportes de ventas.

  • Java
  • Spring Boot
  • SQL

Delivery Bot

Automatización en n8n para los pedidos de una cafetería desde un chat de Telegram. Usa una base de datos con los productos disponibles, su stock y su precio.

  • n8n
  • Telegram
  • Base de datos

Pizzería Don Piccolo

Sistema de gestión de base de datos desarrollado en MySQL para la empresa ficticia Pizzería Don Piccolo. Permite administrar clientes, pizzas, ingredientes, pedidos, pagos, repartidores y domicilios. Además, utiliza funciones, procedimientos almacenados, triggers, consultas y vistas para automatizar diferentes procesos del negocio.

  • MySQL
  • Triggers
  • Procedimientos
  • Vistas

Proyecto de Caffe

Sistema para cafetería que permite facturar, eliminar, actualizar y visualizar los productos disponibles. Tiene un CRUD completo y funciona como carta digital para hacer pedidos.

  • Python
  • CRUD

Ruta Estudiantes

Página en HTML y JavaScript para gestionar rutas y estudiantes, con una sección para cada una. Permite agregar con validación, editar y eliminar.

  • HTML
  • CSS
  • JavaScript

Gestión de Herramientas

Sistema para administrar las herramientas prestadas a los vecinos. Incluye administradores, control de préstamos, gestión de inventario y un CRUD completo.

  • Python
  • Inventario
  • CRUD
